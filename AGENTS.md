Before any work, read **[`.agent/INSTRUCTIONS.md`](.agent/INSTRUCTIONS.md)**.

This repository is **dcmm-desktop**: the macOS-only DeepCleanMyMac AppKit app. Scan/clean logic is **dcmmlib** (`extras/dcmmlib` submodule). App headers live in `include/`. Do not turn this into a cross-platform GUI.

Commits: `FEAT: …` or `FIX: …` (uppercase kind, then an imperative subject). See `.agent/INSTRUCTIONS.md`.

Work on the **`beta`** branch. **`main`** is the functional stable line — do not commit new work there unless the user asks.
